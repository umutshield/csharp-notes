abstract classlar ise bir nevi bu ikisinin yani class ve interface'in birleþimidir. 
abstract hem yarým hem de tamamlanmýþ operasyonlarý(imza) içerir (interfacede operasyon yarým býrakýldý, classta ise tamamlandý öyle düþün).
aþaðýdaki kod çalýþtýrýldýðýnda Kaydet operasyonu tüm mevzuatlarda ortak çalýþýr fakat Degerlendir operasyonu her mevzuat için ayrý yazýlýr.
!! abstract classlar newlenemez !! neden newlenemez? çünkü yarým operasyon( Degerlendir() ) var.
abstract class'ý newleyemezsin ama abstract class'ý implement eden(miras alan) classlarý newleyebilirsin.

abstract class MevzuatBase
{
	protected MevzuatBase()                //abstract class constructor içerir.
	{
		
	}

	public abstract void Degerlendir();
	public void Kaydet()
	{
		cw("Kaydedildi");
	}
}

class AMevzuat : MevzuatBase
{
	public override void Degerlendir()      //override yazmasýnýn nedeni Degerlendir operasyonunun içeriðinin her classta farklý olmasýdýr
	{
		"A mezuatý deðerlendirildi"
	}
}

class BMevzuat : MevzuatBase
{
	public override void Degerlendir()
	{
		"A mezuatý deðerlendirildi"
	}
}
